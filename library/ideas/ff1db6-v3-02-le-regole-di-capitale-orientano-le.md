# Le regole di capitale orientano le scelte degli investitori

Le assicurazioni europee devono tenere fermo un capitale di sicurezza proporzionale al rischio dei titoli che possiedono. Questo capitale non può essere investito per produrre utili, quindi è un costo implicito. Quando la regola cambia il capitale richiesto per un tipo di investimento, cambia anche la convenienza relativa tra le alternative. Secondo l'autore, le scelte di portafoglio dipendono così tanto dalla normativa quanto dal rendimento atteso.
