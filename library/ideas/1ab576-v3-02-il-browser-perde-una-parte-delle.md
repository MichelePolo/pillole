# Il browser perde una parte delle conversioni

Il tracciamento tradizionale dipende dal fatto che il browser dell'utente collabori. Script come pixel e tag vengono bloccati dagli adblocker, Safari limita a sette giorni i cookie impostati via JavaScript e su iPhone l'utente può negare il tracciamento tra app. Anche il rifiuto del consenso riduce i dati disponibili. ==Quando il browser non collabora, le conversioni reali non compaiono nei report==, e ciascuna piattaforma mostra un numero diverso.
