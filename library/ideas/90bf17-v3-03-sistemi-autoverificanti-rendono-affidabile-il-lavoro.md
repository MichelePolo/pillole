# Sistemi autoverificanti rendono affidabile il lavoro con l'IA

Un problema è adatto all'IA quando è possibile costruire attorno ad esso un controllo parzialmente automatico, ad esempio test di proprietà o fuzzing, che un essere umano può predisporre in poco tempo. L'autore ha usato controlli di coerenza incrociata tra regolamenti di gioco contraddittori per ottenere un insieme di regole corretto. Questo approccio costa più token di una via manuale, ma richiede meno tempo umano. Secondo l'autore, molti problemi possono essere affrontati così, anche quando altri sostengono il contrario.
