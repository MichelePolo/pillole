# A repository can be a template

The usual model of open source distribution treats a repository as a product: a stable branch of polished releases, plus an unstable branch of work in progress. The author argues that this may no longer fit. With AI coding tools, users can modify software themselves, and a repository can serve as ==a template that people adapt== to their own requirements, hardware, and problems. Something too unstable for the general public may be exactly right for a smaller group of users. So a codebase that is solid enough to extend can be more valuable than a finished, feature-complete product.
