# L'assione potrebbe risolvere un problema della fisica delle particelle

Nella teoria dell'interazione forte, le cariche elettriche interne del neutrone dovrebbero essere leggermente sfasate, ma le misure le trovano quasi perfettamente allineate. Questo enigma è chiamato problema CP forte. Secondo l'autore, un campo ipotetico di assioni potrebbe spingere le cariche del neutrone nell'allineamento osservato. Per questo l'assione è oggi uno dei candidati più promettenti alla materia oscura ultraleggera, anche se non è detto che spieghi da solo tutta la materia oscura.
