# Il modello predittivo costruisce una forma di astrazione

Secondo l'autore, l'addestramento a prevedere il token successivo costringe il modello a costruire un modello astratto del problema. Questo modello è debole e imperfetto, ma secondo lui deve esistere, perché altrimenti non si spiegherebbero le capacità osservate. L'autore respinge l'idea che gli LLM siano soltanto un ripetitore di parole, pur riconoscendo i loro limiti. È una tesi discutibile, che l'autore sostiene basandosi sulla propria esperienza.
