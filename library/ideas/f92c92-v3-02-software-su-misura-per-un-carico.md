# Software su misura per un carico di lavoro specifico

Un'idea ripresa dall'autore è che il software futuro sarà sempre più adattato a un singolo carico di lavoro, anziché a una classe generica di carichi. Un programma ottimizzato per i dati reali di chi lo usa può superare versioni generiche più solide. Il rischio è però l'overfitting: se il carico cambia rispetto ai dati su cui si è ottimizzato, le prestazioni possono crollare. Servono quindi set di dati di controllo separati per verificare che i miglioramenti reggano.
