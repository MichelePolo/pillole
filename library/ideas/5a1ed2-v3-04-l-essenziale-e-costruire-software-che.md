# L'essenziale è costruire software che funzioni

«Alla fine, l'aspetto più importante di tutti è cercare di rilasciare buon software», scrive l'autore. Nel testo la frase segue una riflessione sulla diversità di sensibilità: chi ha iniziato negli anni in cui tutti erano esperti di licenze le vive con più passione, mentre le generazioni più giovani tendono a un approccio più pratico. Entrambi i punti di vista sono legittimi, ma il traguardo resta lo stesso: un software utile e funzionante. ==La cosa che conta davvero è rilasciare software valido.== È un'idea semplice, spesso dimenticata nei dibattiti sulle licenze.
