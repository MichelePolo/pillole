# La creatività umana conserva un vantaggio sugli LLM

L'autore usa gli LLM ogni giorno per testare idee, fare code review ed esplorare temi ai limiti della propria competenza, ma sostiene che la loro intelligenza resti molto indietro rispetto a quella umana. Secondo lui, le persone sanno pensare fuori dagli schemi e immaginare soluzioni strane e imprecise che funzionano meglio di quelle convenzionali. ==Questo tipo di pensiero laterale resta estremamente difficile per gli LLM.== L'esperienza descritta mostra però anche che un LLM può essere un utile interlocutore per verificare le intuizioni.
