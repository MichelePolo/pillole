# L'apprendimento profondo supera le feature progettate a mano

Secondo l'autrice, i metodi di machine learning tradizionali richiedono di progettare a mano una strategia di feature engineering, compito che spetta agli esperti del dominio. Il deep learning invece apprende da solo le caratteristiche rilevanti dai dati, e questo è utile in un contesto come quello single-cell, dove i dati sono ad alta dimensionalità, non lineari ed eterogenei, con molto rumore e sparsità. La capacità di scoprire pattern senza una selezione manuale è la ragione principale del suo impiego.
