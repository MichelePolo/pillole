# Le affermazioni sulla verifica vanno testate, non date per scontate

Secondo l'autore, molte affermazioni su quali tecniche di test funzionino meglio con gli agenti di programmazione sono spiegazioni dal suono convincente che però non reggono quando si osserva cosa fanno davvero gli agenti. ==Per capire cosa funziona bisogna misurarlo, non fidarsi del buon senso.== L'autore nota che lo stesso vale per gli esseri umani: spesso le ragioni che si ripetono sull'efficacia di un linguaggio o di una tecnica non sono mai state verificate con dati adeguati.
