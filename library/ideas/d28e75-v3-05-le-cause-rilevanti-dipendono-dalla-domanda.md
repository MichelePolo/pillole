# Le cause rilevanti dipendono dalla domanda posta

Secondo l'autore, una spiegazione causale non elenca tutte le cause di un evento, ma seleziona quelle rilevanti per una specifica domanda. Un metodo utile è chiedersi cosa sarebbe accaduto se una causa fosse stata diversa, cioè ragionare in modo controfattuale. Così si distingue una causa esplicativa da una condizione di sfondo, come l'ossigeno nell'aria. Le spiegazioni sono quindi selettive e dipendenti dall'interesse di chi indaga.
