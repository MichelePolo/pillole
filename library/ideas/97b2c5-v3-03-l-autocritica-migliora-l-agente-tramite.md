# L'autocritica migliora l'agente tramite gli errori passati

Un agente può rivedere le proprie azioni passate, individuare gli errori e correggerli nelle mosse future. Nel framework Reflexion, un'euristica decide quando una traiettoria è inefficiente o contiene allucinazioni, cioè ripetizioni identiche di azioni che non cambiano l'osservazione. Le riflessioni generate vengono conservate nella memoria di lavoro e usate come contesto per le richieste successive. L'autore sottolinea che il successo dipende dalla capacità di imparare dal fallimento, come fanno gli esseri umani per tentativi ed errori.
