# Le allucinazioni nascono dalla preferenza per una risposta sicura

Secondo l'articolo, un modello può inventare fonti o fatti perché produrre una risposta con tono autorevole è statisticamente più probabile che ammettere di non sapere, soprattutto se nei dati di addestramento le IA dicono raramente "non lo so". Il fenomeno è quindi una conseguenza diretta del modo in cui il modello è addestrato. ==La confabulazione è il prezzo della fluidità==, non un incidente marginale.
