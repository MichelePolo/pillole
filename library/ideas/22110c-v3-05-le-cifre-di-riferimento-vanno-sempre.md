# Le cifre di riferimento vanno sempre ricostruite, non solo memorizzate

Molti numeri utili, come le latenze o le velocità, si possono derivare da parametri di base del sistema. Memorizzare una tabella serve per il colloquio o per un uso rapido, ma chi deve capire come cambierà un risultato se si modifica qualcosa ha bisogno dei meccanismi sottostanti. L'autore nota che, usando spesso certi numeri, finiscono per restare in memoria senza sforzo. Conoscere la derivazione permette anche di accorgersi quando una cifra è semplicemente sbagliata.
