# Il machine learning è un sottoinsieme dell'intelligenza artificiale

Il machine learning è un ramo dell'intelligenza artificiale che si occupa di algoritmi, cioè insiemi di regole per eseguire compiti computazionali specifici. Il suo principio è esporre un sistema a grandi quantità di dati, spesso presi da internet, così che impari a svolgere il compito. Comprendere questa distinzione aiuta a capire perché l'IA moderna dipenda così tanto dai dati e dall'addestramento.
