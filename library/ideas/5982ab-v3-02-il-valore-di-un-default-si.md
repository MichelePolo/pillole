# Il valore di un default si misura dalla spesa per averlo

Un'idea illustrata dall'autore è che le impostazioni predefinite hanno un valore economico enorme. Google pagava Apple decine di miliardi di dollari per restare il motore di ricerca predefinito, e questo dato contraddice l'idea che i default contino poco e che cambiare sia banale. Se un'azienda paga così tanto per essere predefinita, ==il default è una leva di mercato molto potente==. Ignorare questo dato, secondo l'autore, significa sottovalutare il vantaggio strutturale di chi controlla il punto di accesso agli utenti.
