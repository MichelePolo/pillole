# La fiducia nelle licenze fa vincere l'open source

Secondo l'autore, molti sviluppatori rifiutano di adottare software distribuito con una licenza che non comprendono, e questa diffidenza si moltiplica quando è condivisa da una parte consistente della comunità. Lui stesso, scrivendo Vector Sets, avrebbe usato il codice solo se rilasciato sotto AGPL o un'altra licenza open source che conosceva. Nel tempo questo atteggiamento diffuso può favorire il successo dell'open source anche in un panorama software complesso. La fiducia nel modello di licenza diventa quindi un fattore di diffusione quanto il codice stesso.
