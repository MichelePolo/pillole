# Documentation should also serve coding agents

Software is becoming more malleable, and that changes what documentation is for. If users and their AI tools can modify a system, documentation has to explain how the system works to a machine as well as to a person. Useful documentation tells a coding agent how the system is meant to be changed. The author suggests that a project's docs are part of the interface for anyone who changes the code, not just for those who run it.
