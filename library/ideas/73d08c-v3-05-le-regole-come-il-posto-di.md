# Le regole come il posto di blocco

Secondo l'autore, la disciplina bancaria funziona come l'etilometro: quasi nessuno risulta positivo perché si beve meno prima di guidare. Il controllo educa però solo se chi guida crede di poter essere fermato. Se si diffonde l'idea che un'eccezione si trova sempre, l'effetto svanisce. La credibilità delle regole conta quanto la loro esistenza.
