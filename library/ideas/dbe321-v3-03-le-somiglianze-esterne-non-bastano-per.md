# Le somiglianze esterne non bastano per un modello

Una rete neurale può produrre output simili a quelli umani usando meccanismi causali completamente diversi. Un esempio è una grande rete convoluzionale che classifica le immagini guardando soprattutto la texture, mentre gli esseri umani usano la forma. Anche se il risultato è lo stesso, il modo in cui si arriva è diverso, e questo può essere fuorviante se si applica il modello a domini poco compresi. Per un organismo biologico invece, la continuità meccanicistica tra specie conta più della somiglianza fenotipica.
