# Una riduzione traduce un problema in un altro

Una riduzione è un modo di trasformare ogni istanza di un problema in un'istanza di un altro problema, in modo che la risposta coincida. Se si conosce una riduzione da un problema difficile a un gioco, qualunque metodo capace di risolvere rapidamente il gioco diventa automaticamente un metodo rapido anche per il problema di partenza. Il ragionamento dell'articolo si regge interamente su questo passaggio: ==la difficoltà si trasferisce dal problema originale al livello costruito per rappresentarlo==.
