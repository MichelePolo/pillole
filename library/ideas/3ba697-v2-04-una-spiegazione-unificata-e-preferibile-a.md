# Una spiegazione unificata è preferibile a molte spiegazioni separate

Anche se una regressione infinita di dipendenze ontologiche non è impossibile, può essere respinta per ragioni di parsimonia. Secondo l'autore, Cameron sostiene che un fondamento comune di entità offre una spiegazione unica dell'esistenza di tutte le entità dipendenti, mentre una regressione fornisce infinite spiegazioni separate. Poiché fornire una spiegazione unificata è in generale una virtù teorica, questo costituisce una ragione, pro tanto, per preferire il fondamento. Non si tratta però di una prova che le regressioni siano impossibili.
