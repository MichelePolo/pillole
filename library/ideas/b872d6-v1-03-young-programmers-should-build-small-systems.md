# Young programmers should build small systems themselves

Young programmers without enough experience have not yet built a mental model of how software works, and the author doubts that checking LLM output is the best way for them to learn. He suggests they write small programs themselves instead, such as an interpreter, a small database or a hash table. ==Building these systems teaches how programs really work==. By contrast, reviewing routine code for a client is a poor use of their time. The author admits he is not sure about this, and the question remains open.
