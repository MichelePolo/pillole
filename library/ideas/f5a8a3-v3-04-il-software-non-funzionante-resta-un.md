# Il software non funzionante resta un problema reale

L'autore distingue tra software personale, che può essere imperfetto perché usato solo da chi lo ha scritto, e software commerciale o dichiarazioni pubbliche secondo cui la programmazione sarebbe risolta. Il primo caso è accettabile se si conoscono i limiti; il secondo no. Dire che un problema è risolto dopo aver prodotto software che non funziona è una valutazione errata. Le metriche oggettive, come conversioni, abbandoni e soddisfazione degli utenti, mostrano il vero stato delle cose.
