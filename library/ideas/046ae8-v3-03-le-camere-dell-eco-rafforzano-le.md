# Le camere dell'eco rafforzano le convinzioni

L'autrice osserva che chi rifiutava le misure di protezione durante la pandemia viveva dentro un ambiente che confermava continuamente ciò in cui già credeva. Secondo lei, quelle persone pensavano che proteggersi dalla malattia fosse una questione individuale, senza considerare l'effetto del proprio comportamento sugli altri. Questo meccanismo, in cui le informazioni ricevute rafforzano solo le idee già possedute, rende difficile mettere in discussione le proprie posizioni.
