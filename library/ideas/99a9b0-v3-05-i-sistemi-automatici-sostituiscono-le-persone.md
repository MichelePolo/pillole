# I sistemi automatici sostituiscono le persone quando costano meno

Secondo l'autore, le aziende scelgono spesso un servizio automatico scadente, come un risponditore telefonico, invece di un operatore umano, perché il costo è molto più basso. Un sistema peggiore ma molto economico può quindi battere uno migliore ma costoso. ==Il criterio decisivo è spesso il rapporto prezzo-prestazioni, non la qualità assoluta.== Questo schema spiega la diffusione di molte tecnologie imperfette.
