# Chi progetta per il web deve pensare anche ai dispositivi modesti

Secondo l'autore, molti programmatori danno per scontato che i propri utenti abbiano dispositivi veloci, perché la loro esperienza è ristretta a persone benestanti. In realtà una parte enorme del mondo usa telefoni economici e vecchi computer, e le scelte di chi sviluppa escludono proprio questi utenti. La performance è quindi anche una questione di equità. ==Ignorare i dispositivi lenti significa ignorare una parte grande dell'umanità==.
