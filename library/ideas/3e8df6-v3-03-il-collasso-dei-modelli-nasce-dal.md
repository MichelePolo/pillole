# Il collasso dei modelli nasce dal riciclo dei propri output

Secondo l'autore, i modelli addestrati sugli output di altri modelli tendono a perdere varietà: diventano progressivamente autoreferenziali e perdono le code della distribuzione, cioè le eccezioni e le voci meno comuni. Il rischio è una sorta di autofagia informativa. ==Un sistema che si nutre solo di se stesso si impoverisce.== La diversità delle fonti appare quindi una condizione necessaria anche per la qualità dell'intelligenza artificiale.
