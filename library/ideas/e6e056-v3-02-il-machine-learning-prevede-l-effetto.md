# Il machine learning prevede l'effetto delle varianti

Per capire se una variante genetica nel DNA altera lo splicing, non basta osservarne gli effetti sulle proteine: si può addestrare un modello di machine learning che, a partire dalla sequenza del DNA, stima quanto quella variante cambi l'inclusione dell'esone. Il modello impara a riconoscere le sequenze regolatorie intorno ai microesoni, cioè i siti a cui si legano proteine che favoriscono o sopprimono la loro inclusione. Il vantaggio è applicare il metodo a grandi quantità di dati genetici senza testare ogni variante in laboratorio. ==Un predittore addestrato sui dati di espressione permette di selezionare le varianti da approfondire.==
