# Il machine unlearning rimuove dati dal modello

Il machine unlearning è un'area di ricerca nata nell'IA che mira a eliminare da un modello addestrato le tracce di specifici dati, senza comprometterne le prestazioni. Diversamente dal blocco delle risposte, il modello non dovrebbe più conoscere l'informazione. Secondo l'autore, il campo è ancora agli inizi e presenta difficoltà di efficienza, affidabilità e verificabilità, ma potrebbe offrire una via più adeguata per gestire la richiesta di oblio.
