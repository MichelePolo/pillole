# Nei compiti di programmazione di sistema gli LLM deludono

Secondo l'autore, quando si lavora su programmazione di sistema in C, algoritmi o formati di dati complessi, gli LLM falliscono spesso nel ragionamento richiesto. Anche modelli avanzati hanno prodotto soluzioni deboli, come due funzioni di hash quasi identiche per un bloom filter, oppure una descrizione errata di un formato di quantizzazione. Per un programmatore esperto, la lettura diretta del codice resta spesso più efficace.
