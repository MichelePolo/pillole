# Il cervello come rete di router con code

Un modello teorico citato nel testo, sviluppato da Bratislav Misic e colleghi, descrive le regioni cerebrali come router di internet, dotati di code che conservano i messaggi in attesa di essere inoltrati. Il modello prevede un flusso sproporzionato attraverso aree come l'ippocampo, rispetto a quanto suggerirebbe la sola forza delle connessioni. Questo mostra come assunzioni semplici e interpretabili sull'instradamento possano produrre previsioni non ovvie sui flussi simulati in un connettoma. ==Un modello semplice di instradamento può prevedere flussi non ovvi.== Il testo lo presenta come un lavoro interessante, non come una verità acquisita.
