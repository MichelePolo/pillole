# Il software riprogrammabile prolunga la vita delle macchine

Voyager è stata la prima sonda dotata di un software di bordo riprogrammabile per controllare assetto e strumenti, mentre i satelliti precedenti usavano circuiti fissi o memorie di sola lettura. Questa caratteristica permette di modificare le sequenze operative, spegnere componenti problematici e risparmiare energia anche a distanza di miliardi di chilometri. Riprogrammare a distanza può significare salvare la missione. La fonte sottolinea che molte anomalie sono state risolte proprio così, dalla Terra, durante decenni di operazioni.
