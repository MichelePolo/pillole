# Un sistema umano-nell'anello dipende dagli esperti

Un sistema di apprendimento automatico che si affida a dati etichettati da esperti eredita i loro errori, le loro lacune e i loro interessi. Se gli esperti conoscono poco certe specie, le classificazioni risultano sbagliate; se mostrano preferenze per alcune specie, quelle finiscono sovrarappresentate. L'autore sostiene che questo rischio sia intrinseco a ogni sistema in cui l'uomo partecipa alla produzione dei dati di addestramento.
