# Il machine learning vede strutture che sfuggono all'occhio

Il machine learning è molto bravo a riconoscere strutture e regolarità nei dati. In matematica questo significa che, se si dispone di una grande collezione di oggetti, un algoritmo può imparare le proprietà condivise tra di essi e segnalare quelle ricorrenti. Nel lavoro descritto, le banche dati di varietà di Calabi-Yau e di curve ellittiche sono state il terreno ideale, perché contengono milioni di esempi già organizzati. ==La macchina non dimostra nulla, ma indica dove guardare.== Questo è un ruolo utile, ma non ancora una scoperta.
