# Le regole urbane contano quanto le singole azioni verdi

Nelle città, il verde si valuta su quale territorio si misura. Calcolare la copertura sull'intero territorio comunale, incluse le colline boscate, può nascondere quartieri quasi privi di ombra. Secondo l'autore, la media amministrativa descrive male le condizioni di chi vive in un certo quartiere. Anche le esclusioni dagli obblighi di copertura verde indeboliscono la garanzia di una distribuzione adeguata del verde tra i quartieri.
